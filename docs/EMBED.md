# 温室与自己的网站

温室是一张可以单独打开的静态网页。植物、天气和访客都在浏览器里按日期生成，离线时也能玩，无需 GitHub 活动、实例配置或 review token。

## 离线打开

下载 `garden/index.html`，用浏览器打开。脚本、样式和 SVG 插画都在这个文件里，打开文件就能开始逛。

## 放到现有网站

把 `garden/index.html` 复制到自己网站的静态目录。比如 Astro 和 Next.js 项目可以这样放。

```text
public/
└── garden/
    └── index.html
```

沿用网站原来的方式发布，完成后访问 `/garden/`。如果网站已经用了这个路径，给温室选一个空闲路径。页面会随日期变化，发布一次即可。

想让温室和网站的其他页面连起来，可以在自己的网站里加一个返回链接或导航。模板里的温室页面可以直接复制使用，个人域名和导航留在自己的网站里。

## 作为 iframe 嵌入

温室已经放在同一个网站的 `/garden/` 时，可以把它嵌入其他页面。

```html
<iframe
  src="/garden/"
  title="每日一盆小温室"
  loading="lazy"
  style="display:block;width:100%;height:960px;border:0;border-radius:20px"
></iframe>
```

窄屏下内容可能会变长，记得留出滚动空间。也可以直接加一个“进入温室”的链接，让访客在独立页面里打开。

温室只需要浏览器的普通页面功能，沿用网站已有的权限和安全策略即可。摄像头、定位和麦克风可以保持原来的权限。如果温室和宿主页面用了不同域名，浏览器或网站的 iframe、CSP 策略可能挡住嵌入。这时可以把温室放到同一个网站，或给它一个直接入口。

## 收藏会跟着走吗

收藏和访客印章存在浏览器的 `localStorage` 里。同一来源的页面共享这份存储。换域名、换浏览器，或从本地文件搬到网站后，通常需要重新收藏。第三方 iframe 能否保存记录也取决于浏览器的存储设置。

同源的其他脚本可以访问这份普通存储。具体保存了什么，见[隐私说明](../PRIVACY.md)。

## 修改后更新

改了温室的三个 JavaScript 源脚本后，在源码根目录重新打包。

```sh
python3 -B scripts/build_greenhouse.py
```

把新生成的 `garden/index.html` 复制到你的网站，再走一次原来的发布流程。日期变化仍由浏览器处理。改动种子前缀或存储键之前，先准备迁移，否则已有的植物结果或收藏可能对应不上。
